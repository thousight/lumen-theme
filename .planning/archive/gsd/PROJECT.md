# Project: Lumen Theme

## Vision
A VSCode theme that is minimal, clean, elegant, and high-tech. It includes both light and dark variants.

## Design Principles
- **Minimalist/Modern:** Focus on soft shadows, subtle gradients, and plenty of whitespace.
- **Monochromatic (Dark):** Strictly monochrome with one accent color.
- **Warm Paper (Light):** Off-white background (`#f7f7f4`) with soft text.

## Scope
- VSCode Dark Theme
- VSCode Light Theme
- High-quality syntax highlighting for major languages.
- Elegant UI component styling.
