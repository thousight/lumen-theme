# Changelog

All notable changes to the "Lumen Themes" extension will be documented in this file.

## [0.2.1] - 2026-09-06

### Fixed
- **Lumen Blanc**: Keep the status bar warm white with dark text and matching borders in no-folder and debugging states.

## [0.2.0] - 2026-02-13

### Added
- **Ecosystem Support**: Explicit styling for GitLens, Error Lens, and Todo Tree.
- **Expanded Languages**: Refined syntax highlighting for C/C++, PHP, Shell, and Markdown.
- **Terminal ANSI Colors**: Custom soft palettes for both variants.

### Changed
- **Accessibility**: Audited and improved contrast for punctuation and comments to meet WCAG 2.1 AA (4.5:1).

## [0.1.1] - 2026-02-13

### Changed
- **Lumen Noir**: Updated cursor color to light gray for better neutral aesthetics.

## [0.1.0] - 2026-02-13

### Added
- **Lumen Noir (Dark)**: Strictly monochromatic theme with International Orange accents for logic.
- **Lumen Blanc (Light)**: Warm paper aesthetic with a muted multi-color palette.
- **Precision Syntax Highlighting**: Integrated TextMate and Semantic Token support for TS, Python, Rust, and more.
- **Minimalist Workbench UI**: Flat design with unified backgrounds and 1px borders.
- **Branding Assets**: Initial marketplace metadata and documentation.
